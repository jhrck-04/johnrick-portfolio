# Certificates

Drop your certificate images here using these exact filenames so they show up on the site automatically:

- certificate-1.jpg
- certificate-2.jpg
- certificate-3.jpg

Then open index.html and update the title/issuer text under each certificate
(search for "Certificate title" and "Issuing organization · Year").

Need more than 3 slots? Duplicate one ".cert-card" block in the Certificates
section of index.html, point it at certificate-4.jpg, etc.
